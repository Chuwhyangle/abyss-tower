## 背景

功能层已齐（8 塔 / 12+ 敌人 / 10 主海克斯 / 70 遗物 / 3 张固定地图 / 5 种模式），全部 30 个任务 done、4 个 goal achieved，最近的 REF-001/002/003 也把模拟、UI、服务端结构收口了。现在玩家反馈集中在「打击感不行」。

实机审查（默认画质与高画质各跑一轮，并用 36 敌混战场景复核）确认了三处根因：

1. 首次进入默认是 low 档：30fps、DPR 1、无光晕、无震屏、飘字只留关键事件（`public/js/settings.js`）。新玩家第一眼看到的是被砍掉全部反馈的版本。
2. 命中层几乎不存在：一次命中只有 0.08 秒闪白 + 0.15 秒火花；没有命中音效、没有 hitstop、没有方向性震屏、没有受击位移/挤压/硬直；击杀音只有 35ms、增益 0.012（`public/js/sim/combat-system.js`、`public/js/render/enemy-renderer.js`、`public/js/audio.js`）。
3. 反馈没有节奏：伤害飘字门槛是 12 点且默认「仅关键」，早期波次稀疏，击杀/漏怪/清波缺少演出。

这个 goal 只补表现与反馈，不动任何战斗数值与胜负逻辑。

## 范围

- 默认自动画质：桌面默认高配，弱机/移动端按能力自动降档；30fps、关闭震屏等只作为显式选择，不再作为首次进入的默认。
- 结构化命中事件：每次伤害产出武器类型、暴击、护盾吸收、护甲吸收、致死、位置与目标，供渲染层与音频层消费；事件不改变模拟结果。
- hitstop、定向震屏、镜头冲击、受击挤压/位移/短硬直、死亡碎裂与残影。
- 八种武器各自的命中特效与命中音效：变调、随机化、并发限流、压缩/限幅总线，避免多单位混战爆音。
- 伤害飘字分层：普通 / 暴击 / 破盾 / 护甲 / 治疗；「全部 / 仅关键 / 关闭」三档都成立且不刷屏。
- 击杀金币迸发、漏怪红屏与基地脉冲、清波慢动作与横幅、首领死亡的独立演出。
- 设置护栏：reduced-motion、震屏开关、飘字档位、画质档位只作用于表现，不改变模拟、RNG 顺序与结算。

## 非目标

- 不改战斗数值、平衡、波次结构、经济与计分；不新增塔、敌人、遗物、海克斯或模式。
- 不做精灵图化与美术资源管线（归 GOAL-006）；不重写音频引擎，只在现有 WebAudio 合成上加命中层。
- 不引入第三方运行时依赖或构建步骤。

## 退出条件

- 首次进入的默认画质为自动档：桌面高配、移动/弱机降档；任何档位下完整的命中反馈链可见，30fps 仅作为显式选择。
- 每次伤害都产出结构化命中事件；同一 seed 在反馈开/关、画质高/低下的模拟结果与 RNG 调用序列逐字节一致。
- 八种武器都有可区分的命中音效与命中特效；暴击、击杀、首领命中、破盾各有独立反馈层，并受并发限流与粒子预算约束。
- 伤害飘字在「全部」档可见且不刷屏，「仅关键」档只保留关键事件；破盾、护甲、治疗可辨识。
- 漏怪、清波、首领死亡各有独立演出；reduced-motion 或关闭震屏时仍保留非运动反馈。
- 性能预算不回归：`npm run perf:budget` 通过，战斗场景机械指标（反馈覆盖、对比度、特效预算）通过。
