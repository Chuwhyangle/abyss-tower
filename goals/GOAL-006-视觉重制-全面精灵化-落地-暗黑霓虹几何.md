## 背景

PRD 的视觉定位是「暗黑霓虹几何」，但实机画面是纯程序化平面绘制：深绿草地 + 棕色棋盘路径 + 粉绿卡通小怪 + 金色菱形装饰；三种视觉语言互相打架，装饰与可破坏物比敌人更抢眼，单位在 22×12 的地图上只有 16–28px，缺少统一光源、投影、描边与氛围层。HUD 还存在 12–13px 小字、未解锁塔卡几乎不可读、英文界面里硬编码中文等问题。

人在 2026-10-26 明确选择「全面精灵化」：背景、单位、界面全部走贴图资源；并与打击感双线并行。这个 goal 负责建立资源管线、统一视觉语言、把可读性拉起来，同时守住零第三方运行时依赖与性能预算。

## 范围

- 美术方向与资源规范：`docs/ART_DIRECTION.md`（风格圣经、调色板、材质、发光规则、剪影规则）与 `docs/ASSET_PIPELINE.md`（尺寸、锚点、轴心、帧数、命名、图集、压缩、DPR、授权与出处）。
- 资源管线：预加载与进度、图集/单图加载、DPR 与缩放、缺资源时的程序化占位回退、缓存失效、低配降级、内存上限。
- 背景：地形瓦片、路径/边缘、分层视差、光照叠加、雾/余烬/光池等氛围层，以及可破坏物与传送门的视觉权重。
- 单位：8 塔（含进化形态）、12+ 敌人与首领、召唤物/盟友、可破坏物、传送门、基地的精灵与状态动画（待机/行进/攻击/受击/死亡）。
- 投射物、命中与技能特效的精灵化；与 GOAL-005 的命中事件管线对接。
- UI：标题/选图/战斗/结算四个场景的面板、图标、按钮、卡面皮肤化；保持双语与可读性。
- 视觉回归与评审：确定性场景截图、对比度/字号/剪影/锁定态检查、双语检查、桌面与移动两个视口、前后对照评审记录。
- 性能与降级：图集内存、每帧 drawImage 数、低配档位与回退路径。

## 非目标

- 不改变任何战斗数值、波次、经济、玩法与计分；不新增塔、敌人、遗物、海克斯或模式；不重写模拟层。
- 不引入第三方运行时依赖或构建步骤；图集生成脚本用仓库内 Node 脚本，运行时仍由静态资源直接加载。
- 不替换现有 WebAudio 音频引擎（归 GOAL-005 的命中音效范围）。

## 退出条件

- `docs/ART_DIRECTION.md` 与 `docs/ASSET_PIPELINE.md` 定稿并被测试引用；每个资源都有出处、授权与生成方式记录。
- 标题、选图、战斗、结算四个场景在桌面与移动两个视口下全部走精灵资源；缺失资源时有程序化回退且不崩溃。
- 8 塔（含进化形态）、12+ 敌人与首领、召唤物、可破坏物、传送门、基地都有独立精灵与至少两种状态动画；UI 图标与卡面完成皮肤化。
- 机械视觉检查通过：单位与背景对比度、最小字号、剪影像素覆盖、未解锁卡可读性、双语无缺译与无硬编码。
- 低配可降级到低分辨率图集或程序化回退；`npm run perf:budget` 通过，60fps 目标不回归。
