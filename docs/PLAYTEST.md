# 真人试玩记录

M4 用真人试玩校准三档难度。本表固定记录字段与口径，方便和机器人平衡模拟（[`docs/BALANCE.md`](BALANCE.md)）逐项对照；机器人结果不填此表。

## 记录口径

- **解锁状态分开记录**：`全解锁` 与 `零解锁` 各成一组。两种口径的通关率差异很大（见 `docs/BALANCE.md`），混在一起会失去对照意义。
- **每档建议样本量**：全解锁、零解锁各至少 3 局，每档合计**至少 5 局**；正式调参前建议每档 10 局以上。
- **完整对局才记录**：从开局选图到通关或失败，中途放弃的局不计入。
- **败局更有价值**：失败局必须写清失败波次与失败原因，不要只记通关局。
- **内容版本**：填当次试玩的版本号或提交短哈希（如 `v1.7.0` / `26b4bc7`），便于区分调参前后。

## 字段说明

| 字段 | 取值口径 |
| --- | --- |
| 日期 | `YYYY-MM-DD` |
| 内容版本 | 版本号或提交短哈希 |
| 难度 | 漫游 / 远征 / 深渊（见下方各小节） |
| 解锁状态 | 全解锁 / 零解锁 |
| 地图原型 | 本局选择的地图：单径峡谷 / 双径汇流 / 三径裂隙 / 环形回廊 / 交叉回廊 |
| 词缀 | 富矿 / 疾风 / 薄雾 / 裂界 |
| 结果 | `通关`（清空第 30 波）或 `第 N 波失败` |
| 剩余基地生命 | 结算时的基地生命；失败记 0 |
| 剩余金币 | 结算时的金币 |
| 塔数与关键塔 | 最终塔数 + 承担主要输出的塔，如 `18 塔：电弧×6、毒雾×4、弩炮×8` |
| 关键遗物 | 对局势影响最大的 1–3 件遗物及等级，如 `雷核Ⅲ、护盾Ⅱ` |
| 失败原因 | 按下方分类填**主因**一个：`漏怪类型` / `经济断档` / `塔位失误` / `遗物太差` / `其它`；通关局填 `—` |
| 主观备注 | 体感、卡点、疑似数值问题；可补充次因 |

### 失败原因分类

| 分类 | 判定标准 |
| --- | --- |
| 漏怪类型 | 某种敌人（飞行、护甲、高速、首领等）没有对应解法，成批漏怪 |
| 经济断档 | 金币不足以维持升级/补塔，塔位与强度明显落后于波次 |
| 塔位失误 | 塔的位置覆盖不到关键路径或汇流点，火力浪费 |
| 遗物太差 | 关键遗物缺席或等级过低，构筑无法成形 |
| 其它 | 不属于以上四类；在备注里写清具体原因 |

## 使用说明

1. 每次试玩结束后，把一行填进对应难度的小节；行数不够直接追加。
2. 先填主因（失败原因），次因和细节写进主观备注，避免一格塞多个分类。
3. 汇总时按 **难度 × 解锁状态** 分组统计通关率，再与 `docs/BALANCE.md` 的同口径机器人数据对照；差异持续超过 10 个百分点时，优先排查是否为真人操作上限所致，再考虑调数值。
4. 本表只记录真人数据，不改数值；调参结论沉淀到 `docs/BALANCE.md` 或 PRD 第 4.11 节。
