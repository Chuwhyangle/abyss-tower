## Proposal

GOAL-005 / GOAL-006 由多个并行 worker 落地，视觉与打击感风格可能不一致：调色板、光源/投影、描边、命中特效颜色语言、动效时长、HUD/塔卡皮肤都可能各自为政。人明确裁定：并行不一致不是阻塞项，合并后用一个对齐 task 收口。本任务在剩余四条任务全部落地后，做一次全局一致性审查与修正，并出前后对照。

## Plan

1. 采集全场景 after（title / lobby / map / combat / result × desktop / mobile），跑 `visual-check --suite all --quality high`、`npm run perf:budget`，记录指标。
2. 对照 `docs/ART_DIRECTION.md` 与 `docs/PHASE_FEEL_ART.md` 逐项检查：调色板/发光/描边/阴影是否统一；八种武器命中特效的颜色与时长是否同族；HUD/塔卡/图标字号与对比度；移动端布局。
3. 不一致处优先改共享层（`art-tokens.js` / `palette.js` / `impact-vfx.js` / `render.js` / `styles.css`），不在各实体渲染器里打补丁；保持模拟、数值与 RNG 不变。
4. 重新采集，跑机械套件 + 语义评审，更新 `docs/ART_REVIEW.md` / `docs/FEEL_REVIEW.md`，出 before/after contact sheet。
5. 记录偏差清单（发现 → 处理 → 证据），写入任务 Notes。
