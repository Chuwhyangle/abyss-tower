## Proposal

本地 quay dev 仓库停在 v0.22.0（detached HEAD），上游已到 v0.24.0（v0.23.0 2026-10-26、v0.24.0 2026-10-27）。当前启用的插件是 `quay@quay-dev`，目录源 `/data/home/wenhao/quay/plugin`；driver 也直接运行该目录下的 `driver-anchor.ts`。升级会改变运行中的 driver 代码，因此必须在当前批次全部落地、in-flight worker 归零后手动执行，不能由 worker 自动跑。

风险已知：
- v0.23.0 / v0.24.0 都是 `-dev` tag，不是稳定版。
- v0.24.0 带 BREAKING：`quay init` 不再创建 `<project>/.quay/plugin`；本工作区该路径是 symlink，全仓无代码引用，driver 从 dev 仓库路径解析，影响可控。
- dev 仓库当前有未提交的 `0.22.0-dev → 0.22.0` 版本号改动，升级前需 commit/stash/discard。

## Plan

1. 确认 `quay task list` 无 in-flight、无 ready/todo 阻塞任务；goals 已到期望状态。
2. 备份：记录 `git -C /data/home/wenhao/quay status`、当前 anchor PID 3474935、`.quay/config.yml`。
3. 清理 dev 仓库：处理未提交的版本号改动（commit 或 stash），确认 detached HEAD。
4. `git -C /data/home/wenhao/quay checkout v0.24.0`（保守可选 v0.23.0）。
5. `claude plugin update quay@quay-dev`；确认 `claude plugin list` 版本变成 0.24.0。
6. `quay config validate`、`quay init --dry-run`（观察 `.quay/plugin` 退休行为），必要时迁移 `.quay/config.yml`。
7. 停掉旧 anchor（确认无 in-flight worker），用同一命令行重启 `/data/home/wenhao/quay/plugin/scripts/driver-anchor.ts __anchor --root /data/home/wenhao/abyss-tower`。
8. 跑一个小任务/`quay goal gate` 验证 driver、worker、goal 三环正常；记录新版本与回滚方式。
