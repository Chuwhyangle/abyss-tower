## 背景

MAP-004 已让可破坏物在模拟层生效。本任务把物件画出来、可点击、有确认面板与反馈，让玩家真正“看见并拆掉”它们。

## 要求

- 新增 `public/js/render/destructible-renderer.js`：按类型绘制不同几何图标（金脉/石碑/补给箱/虫巢/图腾），已拆除的绘制废墟/空位；低配画质降级；与现有分层渲染器注册。
- `public/js/render/render.js` 接入新渲染器（只加注册，不改其他层）。
- `public/js/app/input.js`：点击物件命中检测（画布坐标 → 格），打开确认面板；触摸端同样生效；点击其他位置正常取消。
- `public/js/ui/modals.js`：确认面板显示名称、描述、拆除费用、效果、警告（虫巢会生成敌人 / 图腾光环）；确认后调用 `sim.destroyDestructible`，成功 toast/音效，失败提示原因。
- `public/js/audio.js`：拆除音效（合成，无素材），尊重静音。
- i18n：中英文案（物件名、描述、按钮、toast）。
- `public/styles.css`：确认面板与物件提示样式，移动端可用。
- 拆除状态在刷新后保持（依赖 MAP-004 快照）。

## Notes

### 实现

- `public/js/render/destructible-renderer.js`（新增）
  - `DestructibleRenderer` 只读 `game.destructibles` / `game.hover`，绘制五种几何图形：diamond（金脉）/ monolith（石碑）/ crate（补给箱）/ nest（虫巢）/ ring（图腾），未知类型回退方块。已拆除的物件画半透明虚线残框 + 确定性碎石（位置由 id 哈希决定，不闪烁）。
  - `DESTRUCTIBLE_PROFILES` 低/高两档：低配无光晕、无脉冲、无阴影、无细节线；高配才创建 radial gradient 与脉冲。档位由 `glow && decorations === 'full'` 决定（与 `QUALITY_PRESETS` 对齐）。
  - 纯展示模型：`destructibleVisual/destructibleVisuals`（alive/ruined 状态映射）、`destructibleCostSpec`、`destructibleEffectSpec`、`destructibleWarningKey`、`destructibleFailureKey`。放在渲染模块内而不在 `ui/modals.js` 新增导出，是遵守 `tests/ui-split.test.mjs` 的固定导出面。
- `public/js/render.js`：注册并在地面层（L1 之后、塔之前）调用 `destructibleRenderer.render(...)`；未改其它层。任务原文写的 `public/js/render/render.js` 在本仓库不存在，实际聚合门面为 `public/js/render.js`，Touches 已按实际路径修正。
- `public/js/app/input.js`
  - 新增纯函数 `nearestDestructible` / `resolveDestructible`：鼠标精确点格，触屏在 `destructibleSnapRadius = 1.2` 内吸附；已拆除的不响应；旧模拟实现（无 `destructibleAt`）安全返回 null。
  - `handleCanvasClick` 在建造/选塔之前先判定物件命中：命中即 `openDestructible`（先 `cancelSelection`，再打开确认面板）；点空白处继续走原有取消/建造路径，触摸拖动阈值仍然优先。
  - hover 时光标在物件上显示 pointer；`openDestructible` 的 `onResolved` 刷新商店与 HUD。
- `public/js/ui/modals.js`：新增 `showDestructibleConfirm({sim, item, onResolved})`，显示名称/描述/费用/效果/巢穴与图腾警告；确认后调用 `sim.destroyDestructible(item.id)`，成功后 `audio.play('destructible')` + 成功 toast，失败按原因（not-found / already-destroyed / gold-insufficient / 未知）给出双语 toast，并回调整理 HUD。
- `public/js/audio.js`：新增合成音效 `destructible`（低频碎裂 + 噪声 + 清亮收尾），沿用 `play()` 既有静音开关，无音频素材。
- i18n：`data.destructible.*.{name,desc}`（5 类）+ `destructible.*` 面板/警告/toast 共 31 个键，中英双语键集合一致。
- `public/styles.css`：`.destructible-modal / .destructible-facts / .destructible-warning` 等样式；移动端断点下费用/效果改单列、按钮 100% 宽且 `min-height: 44px`。
- 刷新保持：MAP-004 的 `destructibleState` 快照恢复后，`destructibleVisual` 仍映射为 `ruined`，同格 `canBuild` 为 true（本任务测试直接覆盖往返）。
- `scripts/test-changed.mjs`：在 TEST_MAP 登记 `public/js/render/destructible-renderer.js` → `tests/destructibles-ui.test.mjs`，让「审计覆盖当前仓库全部源文件」用例覆盖新增渲染器。
