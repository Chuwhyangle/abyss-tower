## Proposal

UI 外壳存在系统性重复：`public/js` 下 11 个文件各自复制 `function escapeHtml`（`ui/shared.js` 已有一份）；10 个根级 `*-ui.js` 面板各自实现 `PANEL_ID` / `STYLE` / render / click / fetch；`public/js/api.js` 只有 3 个 importer，而 UI 层散落 22 处裸 `fetch('/api…')`，重复处理 `credentials`、401、错误文案与 JSON 兜底。本任务建立统一的 UI kit（模板转义 + 面板生命周期 + API 客户端），把面板收敛到同一骨架并删除重复实现。

## Plan

1. 新建 `public/js/ui/kit/dom.js`：`escapeHtml`、`html` 模板、`hydrate`（从 `ui/shared.js` 迁出并保持兼容导出）。
2. 新建 `public/js/ui/kit/panel.js`：`createPanel({ id, style, load, render, onOpen, onClose })`，统一注册/打开/关闭、加载态、错误态、Esc 关闭与键盘焦点。
3. 在 `public/js/api.js` 增补 `request(path, { method, body })` 薄封装：统一 `credentials: 'same-origin'`、JSON 解析、HTTP 错误映射；UI 面板不得再直接 `fetch('/api…')`。
4. 先迁移 3 个结构最接近的面板（leaderboard / season / daily-history），验证骨架后再迁其余：achievements、bounties、cosmetics、replay、relic-codex、share、stats、notifications、season-pass。
5. 删除各文件本地 `escapeHtml`、重复 STYLE 与 fetch 逻辑；保留各面板自己的渲染函数与业务字段。
6. 新增 `tests/ui-kit.test.mjs`：panel 生命周期单测 + 静态门禁（除 kit 外无本地 escapeHtml、无裸 fetch('/api）。
