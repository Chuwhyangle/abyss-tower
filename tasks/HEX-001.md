## 背景

人要求开局有一个主导整局的主海克斯，效果鲜明、10 个左右、彼此完全不同。本任务建立数据模型、注册表和十个定义；运行时钩子由 HEX-002 接，开局流程由 HEX-003 接。

## 要求

- 新增 `public/js/shared/hexes.js`（门面）与 `public/js/shared/hexes/`（每个海克斯一个模块）：
  - `HEX_ORDER` 固定 10 个 id；`HEXES`/`HEX_BY_ID`；`offerHexes(seed, count=3, mode)`（确定性，不使用全局 Math.random）；`validateHexChoice(id, offers)`。
  - 每个模块导出 `{ id, name, glyph, color, tags, pitch, desc, downside, scoreMul, hooks, implemented }`。
  - 十个 id 与名称：`glass_cannon` 玻璃大炮、`one_tower` 独塔为王、`swarm` 虫群战术、`golden_law` 黄金律法、`relic_devourer` 遗物吞噬者、`undead_legion` 亡者军团、`molten_core` 熔火核心、`gamblers_dice` 赌徒之骰、`mirror_engineering` 镜像工程、`overload_grid` 过载电网。
  - 十个模块先以 `implemented:false` + no-op hooks 创建；HEX-004..013 各自填充并翻为 true。注册表已 import 全部 10 个，后续任务不得改注册表。
- `offerHexes`：按 seed 洗牌取 3；每日/本周用 mode+seed 派生，同 seed 同结果；不足 3 个 implemented 时仍返回已实现项（允许少于 3），不返回 no-op 桩。
- 描述文案（zh/en 由 i18n 提供，数据里给 key 或中文默认）：
  - 玻璃大炮：塔伤害 +70%，但每座塔只有 5 点生命且无法提升；漏怪会伤塔。
  - 独塔为王：只能建 1 座塔，但它能升到 10 级并兼得全部进化。
  - 虫群战术：塔便宜 55%、攻速 +15%，但单塔伤害 -40%、射程 -15%。
  - 黄金律法：开局 +250 金、击杀金币 +45%，但每波结束烧掉 15% 金币，卖塔只返 35%。
  - 遗物吞噬者：遗物四选一、刷新免费 +2 次，但每拿一件遗物基地生命上限 -1。
  - 亡者军团：击杀有 20% 概率召唤骷髅，但击杀金币 -55%。
  - 熔火核心：攻击附带灼烧，但攻击间隔 +25%。
  - 赌徒之骰：每波随机运势+代价，遗物完全随机、刷新 +1。
  - 镜像工程：建塔时对称位置生成 60% 属性镜像塔，但造价 +35%。
  - 过载电网：相邻塔提供攻速/伤害加成，但射程 -20%。
- `scoreMul` 依次：1.15 / 1.20 / 1.05 / 1.10 / 1.10 / 1.15 / 1.05 / 1.10 / 1.10 / 1.05。
