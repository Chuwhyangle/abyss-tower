## 背景

固定地图与可破坏物落地后，需要平衡、文档和浏览器级验收，避免“能跑但不好玩/不可发现”。

## 要求

- 用 `npm run balance`/`npm run sweep` 对三张固定图跑机器人样本；记录每张图三档难度的通关率与平均波次；目标不劣于 v1.31 随机图的区间（漫游 70–85%、远征 25–40%、深渊 5–12%）；偏差超过 5 个百分点时调整敌人数量/金币而不是改路径。
- 更新 `docs/MAP_DESIGN.md`：三张固定图的路径、塔位、可破坏物、固定 trait、设计意图。
- 更新 `docs/GUIDE.md`：地图三选一、可破坏物操作、五种物件效果。
- 更新 `docs/BALANCE.md`：固定图平衡样本与结论。
- 新增 `tests/browser-map-v2.mjs` 并接入 `package.json` 的 `verify:browser`：开局选三张图、点击拆除一个免费物件、确认状态变化。
- 不调整已冻结的战斗公式。
