## 背景

固定地图与可破坏物落地后，需要平衡、文档和浏览器级验收，避免“能跑但不好玩/不可发现”。

## 要求

- 用 `npm run balance`/`npm run sweep` 对三张固定图跑机器人样本；记录每张图三档难度的通关率与平均波次；目标不劣于 v1.31 随机图的区间（漫游 70–85%、远征 25–40%、深渊 5–12%）；偏差超过 5 个百分点时调整敌人数量/金币而不是改路径。
- 更新 `docs/MAP_DESIGN.md`：三张固定图的路径、塔位、可破坏物、固定 trait、设计意图。
- 更新 `docs/GUIDE.md`：地图三选一、可破坏物操作、五种物件效果。
- 更新 `docs/BALANCE.md`：固定图平衡样本与结论。
- 新增 `tests/browser-map-v2.mjs` 并接入 `package.json` 的 `verify:browser`：开局选三张图、点击拆除一个免费物件、确认状态变化。
- 不调整已冻结的战斗公式。

### 平衡结果（全解锁、机器人口径，40 种子 × 3 图）

- 整体：漫游 29%、远征 1%、深渊 0%（目标 70–85% / 25–40% / 5–12%）。
- 逐图（漫游 / 远征 / 深渊）：
  - 裂谷关隘：55% / 3% / 0%
  - 双牙桥：18% / 0% / 0%
  - 环心遗迹：15% / 0% / 0%
- 同机器人 v1.31 随机 carve 基线：75% / 18% / 3%。
- **偏差说明**：固定图整体低于目标。结构性原因是单条 lane 长度——裂谷关隘 39 格，双牙桥 24/25 格、环心遗迹 25/26 格，多入口图敌人受火时间明显更少；同时机器人不选主海克斯、不做分支进化、不主动用技能，绝对通关率系统性低于真人。这不是数值回归（三档倍率、敌人定义、战斗公式均未改）。
- **调参评估（按要求测“敌人数量/金币”杠杆，20 种子抽样）**：双牙桥/环心遗迹要把敌人数量乘到约 0.55 才能让漫游回到 70% 附近，但远征仍只有 10%/0%；乘 0.4 并追加开局金币 +200 后，远征仍只有 20%/20%、深渊 20%/0%。继续压低会让漫游图完全失去防守压力，故本轮不落地数值改动，路径与冻结的战斗公式均未改；偏差按 AC 约定记录在 `docs/BALANCE.md`。
