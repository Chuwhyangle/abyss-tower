## 背景

HEX-001/002 已有数据与运行时框架。本任务把主海克斯接入开局流程：服务端生成三选一、校验选择、写入 ruleset/快照、计分，以及开局 UI。

## 要求

- 服务端：
  - `create` 返回 `hexOffers`（3 个 id）；每日/本周用 day/week seed 派生，同组所有人一致。
  - 新增 `POST /api/runs/:id/hex`，body `{hexId}`；`RunRoutes` 正则与 `RunService.chooseHex` 校验 id ∈ offers，写入 `ruleset.hex = {id, offers, poolVersion:'hex-v1'}`；重复选择幂等，选后不可改。
  - `serialize/active` 返回 `hex`、`hexOffers`；`serveWave/finish` 从 ruleset 读 hex。
  - `run-service.relicOffers` 调用 `relicOfferCount`/`relicRerollCost`（从共享 hex 定义读），支持遗物吞噬者与赌徒之骰的服务端部分。
  - 结算计分：`scoreMul *= hex.scoreMul`；run 结果与回放记录 `hexId`；旧 run 无 hex 时按 1.0。
- 客户端：
  - `public/js/app/run.js` 流程改为 create → 海克斯三选一 → 地图三选一 → beginGame；刷新恢复同样的选择顺序与同一组 offers。
  - 新增 `public/js/ui/hex-select.js`（或 modals 中的独立面板）：3 张卡片显示名称、图标、定位标签、强项、代价、scoreMul，确认后不可返回；中英双语；移动端可用。
  - HUD/标题页显示已选海克斯徽标与 tooltip；局内可见。
  - `public/styles.css` 增加选择卡片与徽标样式。
- 分享码/回放：格式版本 +1，编码 hexId；旧码 decode 为 null。
- 不改具体海克斯效果（HEX-004..013）。

## Notes

**实现**

- 服务端：`hexOfferSeed(run)` 派生三选一 seed（daily → `daily:<day>`、weekly → `weekly:<week>`，其余按本局 seed），同一 run 与同组每日/本周所有人恒定；注册表尚无 `implemented: true` 定义（HEX-004..013 未落地）时从完整 `HEX_ORDER` 池派生，保证三选一始终有 3 张。
- `RunService.chooseHex`：id ∉ offers → 400 `INVALID_HEX`；已选换 id → 409 `HEX_LOCKED`；重复同 id → 200 `alreadyChosen:true`；开局放行波次后不可选。写入 `ruleset.hex={id,offers,poolVersion:'hex-v1'}`（新增 `db/runs.setRuleset`）。`serialize/active` 返回 `hex`/`hexOffers`，`serveWave` 回传 `hex`。
- 遗物服务端：`relicOffers` 经 `HexRuntime.relicOfferCount/relicRerollCost` 取候选数与刷新费（默认 3 / 25），响应新增 `offerCount`/`rerollCost`，供 HEX-008/011 填数值。
- 计分：`scoring.hexScoreMul`（缺失/未知 → 1.0）乘入 `scoreMul`，反作弊上下限同步放宽；`replaySummary.hex`、`replayResult.hexId`、`settle().hexId` 均记录；`db/replays.hydrateReplay` 暴露 `hex`。
- 分享码：`REPLAY_VERSION=2`，payload 新字段 `h`。解码同时接受 v1（旧码 `hexId` 为 null）与 v2；v1 出现 `h` 按 `REPLAY_UNKNOWN_FIELD` 拒绝。`share-ui.buildRunPayload` 带 `hexId`（`run.hexId ?? sim.hex.id`）。
- 客户端：`RunController.startSelectionFlow` / `showHexSelectFlow` 实现 create → hex → map → beginGame；`restorePendingMap` 在未选海克斯时按服务端 `hexOffers` 恢复三选一，已选则直接选图；`beginGame` 把 `hex`/`hexState` 传给 `Simulation`，续玩从快照 `hexId/hexState` 恢复；HUD/标题页徽标由 `ui/hex-select.js` 的 `HexBadge` 统一渲染（`data-tip` 复用既有 tooltip），最近一局记入 `localStorage` 供标题页展示。
- UI：新面板 `public/js/ui/hex-select.js`（卡片：图标/定位标签/强项/代价/scoreMul；点选→确认两步，`closable:false` 不可返回）；`ui.js` 挂载 `hexSelectMethods`；中英各补 10 个海克斯的 name/pitch/downside/tags 与 10 个面板文案。
