## 背景

当前地图由 7 种原型按种子随机 carve（`public/js/shared/mapgen.js` 的 `carve`/`buildLayout`），每局地形不可记忆，也无法放置固定可破坏物。人要求改为三张固定、可复用、有记忆点的手工地图。

## 要求

- 新增 `public/js/shared/maps/`：
  - `index.js`：导出 `FIXED_MAPS`（3 张，顺序固定）、`FIXED_MAP_BY_ID`、`fixedMapCandidates(seed)`。
  - `rasterize.js`：把 lane 的 waypoints（`[c,r]` 数组）栅格化为 4 邻接 cell 列表，生成与现有 map 对象完全兼容的 `lanes / spawns / base / pathCells / polyline / spawn / blocked / buildable`；校验越界、非 4 邻接、重复点、路径长度。
  - `canyon.js` / `twin.js` / `ring.js`：三张地图数据。
- 三张地图（22×12）：
  - `canyon` 裂谷关隘：单入口，waypoints `(0,3)→(5,3)→(5,8)→(11,8)→(11,2)→(16,2)→(16,9)→(20,9)`，基地 `(20,9)`。固定 trait：无。scoreMul 0.95。
  - `twin` 双牙桥：两入口汇流。A `(0,2)→(7,2)→(7,5)→(13,5)→(18,5)→(20,5)`；B `(0,9)→(7,9)→(7,6)→(13,6)→(18,6)→(18,5)→(20,5)`，基地 `(20,5)`，汇流点 `(18,5)`。固定 trait：商路（击杀金币 +10%，敌人生命 +8%）。scoreMul 1.00。
  - `ring` 环心遗迹：两入口绕环后汇流。A `(0,1)→(16,1)→(16,4)→(18,4)→(18,5)→(20,5)`；B `(0,10)→(16,10)→(16,7)→(18,7)→(18,5)→(20,5)`，基地 `(20,5)`。固定 trait：回响（塔射程 +8%，敌人移速 +6%）。scoreMul 1.08。
- 每张图固定 8–12 个装饰岩石（`rocks`），位置写死在数据里，不使用 RNG。
- `buildable` = 非路径 && 非岩石 && 非固定阻挡；`modifier` 用该图固定 trait（schema 与现有 `MAP_MODIFIERS` 一致）；`meta` 字段保持现有契约。
- `generateMapCandidates(seed, count)` 改为返回三张固定图（顺序固定 canyon→twin→ring，count 截断）；`generateMap(seed)` 指向 canyon 以兼容旧调用。旧随机 carve 实现保留为 `legacyGenerateMap` 导出，仅供旧存档回退，默认路径不再调用。
- 不允许用 RNG 生成几何；同一 map id 每次输出必须完全一致（深比较）。

## Notes

### 实现

- 新增 `public/js/shared/maps/`：`rasterize.js`（waypoints→4 邻接 cell、完整 map 对象、越界/斜线/重复点/自交/长度/基地收束/岩石与阻挡/汇流点校验）、`canyon.js` / `twin.js` / `ring.js`（waypoints、基地、汇流点、固定岩石、固定 trait）、`index.js`（`FIXED_MAPS` / `FIXED_MAP_BY_ID` / `FIXED_TRAITS` / `fixedMapCandidates`）。
- `FIXED_MAPS` 深冻结；每次候选返回深拷贝，调用方修改副本不会污染后续对局。
- `mapgen.js`：`generateMapCandidates` 返回固定三图（count 截断，最多 3）；`generateMap` 指向 canyon；旧 carve 保留为 `legacyGenerateMap` 与 `buildCandidate`（旧存档/回放、legacy 测试用）。`MODIFIER_BY_ID` 合并固定 trait（trade/echo），存档与历史面板可按 id 反查。
- `scoring.js`：每日/每周挑战词缀改由固定地图 trait 派生（canyon 无 trait → 不计入），与候选地图逐项一致；否则 `run-service` 的「种子词缀 = 候选词缀」一致性校验会在真实对局 500。服务端/UI 的全量接入仍由 MAP-002 负责。
