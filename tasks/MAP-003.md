## 背景

人反馈地图没有可破坏物。需要在三张固定地图上放置固定、可交互、一次性拆除的场景物件。本任务只做数据模型与布点，模拟/渲染由 MAP-004/005 接。

## 要求

- 新增 `public/js/shared/destructibles.js`：
  - `DESTRUCTIBLE_TYPES`：`vein` 金脉、`obelisk` 石碑、`cache` 补给箱、`nest` 虫巢、`totem` 诅咒图腾。
  - 每个类型字段：`id/name/glyph/color/desc/cost/effect`；效果为纯函数或声明式数据（gold、maxHp、towerDamageMul、spawn、aura）。
  - 导出 `validateDestructible(obj, map)`、`DESTRUCTIBLE_BY_ID`。
- 三张地图数据增加 `destructibles` 固定数组（位置写死，每项 `{ id, type, c, r }`）：
  - canyon 6 个：2 金脉、1 石碑、1 补给箱、1 虫巢、1 图腾。
  - twin 7 个：2 金脉、2 石碑、1 补给箱、1 虫巢、1 图腾。
  - ring 9 个：3 金脉、2 石碑、2 补给箱、1 虫巢、1 图腾。
- 数值：
  - 金脉：拆除 50 金，获得 110 金。
  - 石碑：拆除 70 金，全塔伤害永久 +5%（每局最多叠 3 层）。
  - 补给箱：免费，获得 25 金并回复 1 点基地生命（不超过上限）。
  - 虫巢：免费，立即在巢穴位置生成 6 只当前波次的噬虫（`swarm`），并开放该塔位。
  - 诅咒图腾：存活时所有敌人移速 +8%、生命 +10%；拆除 80 金后解除。可破坏物本身占一个可建造格。
- 校验：不能放在路径/岩石/基地/出生点；id 全局唯一；每张图至少 1 个可免费拆除的物件；所有物件距出生点和基地至少 2 格。

## Notes

### 实现

- 新增 `public/js/shared/destructibles.js`（自包含纯数据/纯函数模块，不依赖 sim/render）：
  - `DESTRUCTIBLE_TYPES` 固定顺序（vein/obelisk/cache/nest/totem）且深冻结；`DESTRUCTIBLE_BY_ID` 为 type id → 定义注册表；`MIN_SPAWN_DISTANCE = 2`。
  - 效果全部是声明式纯数据（无函数、可 JSON round-trip），sim 与 UI 直接读：`vein {gold:110}`、`obelisk {towerDamageMul:0.05,maxStacks:3}`、`cache {gold:25,baseHp:1}`、`nest {spawn:{enemy:'swarm',count:6}}`、`totem {aura:{enemySpeedMul:1.08,enemyHpMul:1.1}}`；费用 50/70/0/0/80。
  - `validateDestructible(obj, map)`：类型、坐标、路径/岩石/可建造、基地/出生点、距出生点与基地 ≥2 格（切比雪夫，含斜向相邻）、同图 id 与格子唯一；返回 `{ ok, errors:[{ code, detail }] }` 而不是抛错。
  - `validateDestructibles(map)`：逐件校验 + 每张图至少一个免费物件（空布点的旧 spec/合成地图不要求）。
  - `isFreeDestructible` / `destructibleTypeOf` / `markDestroyed(destroyedIds, id)`：后者是纯函数，同一 id 第二次返回 `already-destroyed` 且不追加，保证一局内效果只生效一次（MAP-004 可直接复用）。
- 三张图在 `maps/canyon.js` / `twin.js` / `ring.js` 写死 `destructibles`，id 全局唯一（`canyon-vein-1` … `ring-totem-1`），全部落在可建造格、避开路径/岩石/基地/出生点，每张图都带 cache + nest 两个免费物件。
- `maps/rasterize.js`（新增进 Touches）：`buildFixedMap` 深拷贝 `spec.destructibles` 进 map 对象，并在声明了布点时跑 `validateDestructibles`，非法布点在构建期即抛 `MapSpecError('destructibles-invalid')`；MAP-004 因此可直接消费 `map.destructibles`。`buildable` 保持地形语义（不扣除布点格）：是否可建由 MAP-004 按存活状态判定，拆除后格子自然恢复可建造。
- 未改 sim / render / UI（留给 MAP-004/005）。
